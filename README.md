--start_index: it is the index of the frame you start to sample, which should be 0 if you want to start it from the beginning of the video.--ns: number of seconds you want to extract. Make it the length of your video in seconds if you want to extract all.--nfps: number of frames to be extracted per second.--sampling: if true, it will sample based on the above configuration.--nframes: it will only be used for testing when --sampling is false so it will just export the first number of frames from the video.
